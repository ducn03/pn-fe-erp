# pn-fe-erp (Premier Nuts ERP - Frontend)

Giao diện người dùng Web dành cho hệ thống quản trị doanh nghiệp **Premier Nuts ERP**.

## 🛠 Công nghệ sử dụng
- **Framework:** Svelte 5 (phiên bản mới nhất với Runes)
- **Meta-framework:** SvelteKit 3.x
- **Build tool:** Vite 8
- **Ngôn ngữ:** TypeScript
- **Node.js:** Node v24 (tương thích cả Node 20 LTS)

## 🚀 Khởi chạy dự án

### Cài đặt dependencies (nếu cần):
```bash
npm install
```

### Chạy Development Server:
```bash
npm run dev
# Mở tự động trên trình duyệt:
npm run dev -- --open
```

### Kiểm tra kiểu (Type check):
```bash
npm run check
```

### Build cho môi trường Production:
```bash
npm run build
npm run preview
```
